# Kéire Hub fonts

- `Inter-Variable.ttf` is pinned to `google/fonts` commit
  `c28e08582e7bd36751febb3391142a5eb18bbb34`, file `ofl/inter/Inter[opsz,wght].ttf`, SHA-256
  `29160a80ff49ddcab2c97711247e08b1fab27a484a329ce8b813d820dc559031`. It is distributed under the
  SIL Open Font License 1.1 in `Inter-OFL.txt`.
- `MaterialSymbolsRounded-Subset.ttf` is derived from the rounded variable font at
  `google/material-design-icons` commit `50f0603134ce7b70b2d71b686cc13e8b57ccb74c`, source SHA-256
  `619eaa2f2e270723cf0cd06d2aba126ade66fee94e380c3e6a61e2e496279e0c`. It is distributed under the
  Apache License 2.0 in `Material-Symbols-Apache-2.0.txt`.

The Material Symbols subset contains the code points used by the Hub and Editor shells, including the scene tools,
orientation, snapping, camera, physics, collider-editing, and panel lock controls. The subset was generated with
FontTools 4.63.0.
