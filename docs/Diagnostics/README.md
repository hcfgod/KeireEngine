# Structured diagnostics

Diagnostic IDs are stable `KEIRE-<DOMAIN>-NNNN` values. The editor resolves these packaged pages before opening the
configured online documentation root. Reports may add a source location and key/value context without changing the
meaning of the ID.

- [KEIRE-AUDIO-0001](KEIRE-AUDIO-0001.md): audio streaming underrun
- [KEIRE-REPLAY-0001](KEIRE-REPLAY-0001.md): deterministic replay divergence
- [KEIRE-REPLAY-0002](KEIRE-REPLAY-0002.md): replay session or recording finalization failure
