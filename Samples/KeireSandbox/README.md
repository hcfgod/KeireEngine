# Kéire Sandbox

This project exercises Kéire's editor, asset pipeline, managed scripting, rendering, physics, VFX, and audio workflows.

## Shader and Material Graph gallery

Open `Assets/Scenes/ShaderMaterialShowcase.keirescene` for a staged progression of nine paired Shader Graph and
Material Graph examples. The first row covers approachable paint, texturing, and emissive workflows; the second adds
clear coat, adaptive technical surfaces, and anisotropy; the final row demonstrates transmission, vertex displacement,
and a holographic Voronoi surface. Each Material Graph references its matching custom Shader Graph and exposes the
parameters intended for material authors.

The gallery is the Sandbox startup scene so a newly created Sandbox project opens directly into the examples. The
original `SampleScene.keirescene` remains available as the broader gameplay, VFX, UI, physics, and audio sample.

The files under `Assets/Audio` named `InterfaceConfirm.wav` and `SpatialEmitter.wav` are deterministic synthetic test
tones generated by `Scripts/Assets/generate-sample-audio.ps1`. They contain no third-party samples and are distributed
under the repository's `LICENSE.txt`.
