# Kéire Sandbox

This project exercises Kéire's editor, asset pipeline, managed scripting, rendering, physics, VFX, and audio workflows.

The files under `Assets/Audio` named `InterfaceConfirm.wav` and `SpatialEmitter.wav` are deterministic synthetic test
tones generated by `Scripts/Assets/generate-sample-audio.ps1`. They contain no third-party samples and are distributed
under the repository's `LICENSE.txt`.
