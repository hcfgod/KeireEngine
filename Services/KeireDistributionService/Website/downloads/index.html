Known boundaries

Linux ARM64, Alpine/musl, macOS, and Metal are not yet claimed as tested public-download targets.

Trust by construction

No mystery download buttons.

Signed releases must match unexpired stable catalogs. Development previews are kept outside that trust channel, retained by immutable digest-suffixed name, and labeled unsigned everywhere they appear.

Signed catalog

Stable release metadata is published as exact bytes under an offline Ed25519 signature with an explicit key, sequence, and expiry.

Verified availability

The page validates metadata and confirms the advertised artifact is present before enabling any preview or stable download button.

Visible identity

Hub version, editor version, architecture, byte size, publication date, and complete SHA-256 remain visible before download.
