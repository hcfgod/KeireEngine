Kéire Hub downloads

Your projects.
One place to begin.

Kéire Hub manages projects, editor installations, templates, components, downloads, and updates. Signed stable installers use Hub’s catalog trust path; explicitly marked development previews are offered separately while release signing is completed.

Trust by construction

No mystery download buttons.

Signed releases must match unexpired stable catalogs. The temporary Windows preview is kept outside that trust channel and labeled unsigned everywhere it appears.

Signed catalog

Stable release metadata is published as exact bytes under an offline Ed25519 signature with an explicit key, sequence, and expiry.

Verified availability

The page validates metadata and confirms the advertised artifact is present before enabling any preview or stable download button.

Visible identity

Version, architecture, byte size, and complete SHA-256 remain visible before download so the selected artifact can be independently checked.
