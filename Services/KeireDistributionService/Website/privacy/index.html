Privacy

Minimal collection.
Plain language.

The public Kéire website and distribution service collect only the operational request data needed to serve and protect the site.

What is not collected

This website uses no analytics, advertising, tracking pixels, cookies, newsletter forms, embedded social widgets, or third-party fonts and scripts. It does not create website accounts or attempt to identify visitors across sites.

Contact messages

If you use the Contact form, Kéire stores the name, email address, topic, subject, message, submission time, and review status you provide. Supabase processes and stores those submissions for Kéire so the project can understand and respond to the inquiry. Messages are kept until they are resolved or no longer needed.

For abuse prevention, the contact endpoint stores a one-way keyed hash derived from the request’s network address. The raw address is not placed in the contact database. Rate-limit records older than 24 hours are deleted during normal endpoint use. Do not send passwords, secret keys, or vulnerability details through the general form; use the linked private security workflow instead.

Operational access logs

Caddy writes ordinary structured access logs for security, availability, abuse investigation, and troubleshooting. Those records can include request time, requested path, response status, transferred bytes, source network address, protocol details, referrer, and user-agent information supplied by the browser. The deployed rotation keeps up to ten 100 MiB files and removes records older than 720 hours, approximately 30 days.

Catalogs and downloads

The Downloads page requests public signed catalog metadata from the same origin. Choosing a package makes a normal HTTPS request for that immutable artifact. No download entitlement, account session, or marketing profile is created by the website.

External services

The Contact form sends directly to Kéire’s Supabase project. Links to GitHub leave this site and are governed by GitHub’s own privacy terms. Kéire Hub’s optional Supabase account feature is a separate desktop product capability.

Questions about this notice can be raised through the supported project routes on the Contact page.
